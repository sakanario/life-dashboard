# Button

Pill buttons with lowercase, wide-tracked labels. **Primary** (`sc-btn--primary`, orange) is the one main action in a view. **Surface** (`sc-btn--surface`) is for secondary actions sitting on teal, such as "logout". **Navy** (`sc-btn--navy`) is the tiny "MORE" pill at the foot of a card; CSS sets its label in spaced capitals.

The consumer provides the label and the click handler. Text on orange is `on-orange`, never white.
