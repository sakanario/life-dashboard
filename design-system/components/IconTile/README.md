# IconTile

A large rounded square holding one bold filled glyph. Orange (`radius-xl`, 88px) for navigation hubs such as the app grid; navy (`radius-md`, 64px) for media controls such as play. The orange and navy `sc-swatch` pair is a decorative brand mark, not a control.

The consumer provides the glyph as inline SVG drawn with `currentColor`, and an `aria-label`.
