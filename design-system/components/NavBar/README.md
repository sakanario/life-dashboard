# NavBar

A transparent top bar on the teal ground: a hamburger whose lines shorten downward, text links in `nav` (the current page at full ink, the rest at 55%), and on the right a surface pill for the account action beside the user or product name.

The consumer provides the links, marks the current one with `aria-current="page"`, and supplies the menu behaviour. Collapse the text links into the menu below 720px.
